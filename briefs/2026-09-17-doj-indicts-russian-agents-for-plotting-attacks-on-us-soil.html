DOJ Indicts Russian Agents for Plotting Attacks on US Soil

BREAKING: The DOJ has indicted Russian agents for plotting attacks on US soil. Named defendants. Federal charges. This is not a threat assessment — it's a criminal indictment.

The indictment describes the defendants as part of a network that is 'one arm of the Russian Federation's apparatus used to carry out external attacks' worldwide — not rogue actors, a state apparatus.

The US has charged Russian agents before. They rarely show up for trial. But indictments still matter: they name names, freeze assets, and put allies on notice about who exactly is running these operations.

The bigger question: if Russia is running a global attack network that includes US targets, what's the actual consequence beyond a federal filing? That answer will define how seriously this is taken.
